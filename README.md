A two-sentence horror story — the second sentence turns the first:

> For three nights, my son has woken screaming that the woman under his bed is getting closer. Tonight he slept soundly — because she is under mine now.

`main.ts` prints the story to stdout and writes it to `/output/entry.txt`, after checking the brief's gate: exactly two sentences, 1–400 characters, not only whitespace.

## Run it

```sh
node main.ts
```
